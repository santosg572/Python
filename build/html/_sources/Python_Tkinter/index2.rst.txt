Tkinter
===================================


Tkinter es la biblioteca estándar de Python para crear interfaces gráficas de usuario (GUI, por sus siglas en inglés). Funciona como una capa de enlace 
(binding) orientada a objetos sobre Tcl/Tk.


**Características principales**

• Viene integrada: Se instala por defecto junto con la mayoría de las distribuciones oficiales de Python en Windows y macOS (en Linux a veces requiere un paquete adicional como python3-tk).
• Ligera y rápida: Es ideal para aplicaciones de escritorio pequeñas, herramientas internas, calculadoras o formularios sencillos.
• Independiente de la plataforma: Los programas creados con Tkinter funcionan en Windows, Linux y macOS.
• Documentación oficial: Puedes consultar la guía completa en la documentación de Python - Módulo Tkinter.
