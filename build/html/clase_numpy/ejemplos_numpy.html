amax

Devuelve el máximo de un arreglo o el máximo a lo largo de un eje.

Ejemplos:

import numpy as np

mat = np.round(np.random.normal(loc=55, scale=7, size=(5,4)))

print(mat.max())
print(np.max(mat))
