clase_random

  • random.choice = choice(seq) - Choose a random element from a non-empty sequence.

  • random.choices = choices(population, weights=None, *, cum_weights=None, k=1) - Return a k sized list of population elements

chosen with replacement.

  • random.gauss = gauss(mu=0.0, sigma=1.0) - mu is the mean, and sigma is the standard deviation.

  • random.randint = randint(a, b) - Return random integer in range [a, b], including both end points.

  • random.random = random() - random() -> x in the interval [0, 1).

  • random.randrange = randrange(start, stop=None, step=1) - Choose a random item from range(stop) or range(start, stop[, step]).

  • random.sample = sample(population, k, *, counts=None) - Chooses k unique random elements from a population sequence.

  • random.uniform = uniform(a, b) - Get a random number in the range [a, b) or [a, b] depending on rounding.
