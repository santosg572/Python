Crear Paginas WEB¶

Dado el siguiente codigo, crear un archivo HTML, que pueda desplegar en pantalla uno o varios archivo(s) PDF:

 <!DOCTYPE html>
 <html>
 <head>
 <title>Page Title</title>
 </head>
 <body>

 <h1>This is a Heading</h1>
 <p>This is a paragraph.</p>

 </body>
</html>

Ayuda:

<embed
   src="CleanCode.pdf"
   type="application/pdf"
   width="100%"
   height="600px"
/>
