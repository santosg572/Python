DEFINICIÓN¶

La Programación Orientada a Objetos (POO) es una forma de escribir código que usa “objetos” para representar cosas del mundo real. Junta los datos de un elemento y las acciones que puede hacer en un solo lugar. Ayuda a que los programas grandes sean más fáciles de ordenar y cambiar.

Elementos Principales

  • Clase: Es un molde o plantilla. Define cómo van a ser los objetos.

  • Objeto: Es una copia real creada a partir de esa clase.

  • Atributo: Son los datos o características del objeto (como color o tamaño).

  • Método: Son las acciones que el objeto puede hacer (como correr o frenar).

Los 4 Pilares de la POO

  • Abstracción: Muestra solo lo importante y oculta los detalles difíciles.

  • Encapsulación: Guarda los datos dentro del objeto para que nadie los cambie por error.

  • Herencia: Permite que una clase nueva use los datos y acciones de otra clase vieja.

  • Polimorfismo: Permite que distintas clases usen una misma acción con resultados diferentes.
