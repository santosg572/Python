Módulo Numpy¶

Este módulo esta construido de varias clases, principalmente para el manejo de arreglos.

Ejemplos.

import numpy as np

a = np.array([1, 2, 3, 4, 5, 6])

len(a)

a[0] = 10

a[4:]

a
