Números Binarios
================

.. list-table:: Conversión ENTRE Números
   :widths: 25 50 
   :header-rows: 1

   * - Número natural
     - Número binario
   * - 0
     - 0= :math:`0 \times 2^0`
   * - 1
     - 1= :math:`1 \times 2^0`
   * - 2
     - 10 = :math:`1 \times 2^1 + 0 \times 2^0`
   * - 3
     - 11 = :math:`1 \times 2^1 + 1 \times 2^0`
   * - 4
     - 100 = :math:`1 \times 2^2 + 0 \times 2^1 + 0 \times 2^0`
   * - 5
     - 101 = :math:`1 \times 2^2 + 0 \times 2^1 + 1 \times 2^0`
