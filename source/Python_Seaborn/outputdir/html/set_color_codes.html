set_color_codes¶

Help on function set_color_codes in module seaborn.palettes:

set_color_codes(palette='deep')

Change how matplotlib color shorthands are interpreted.

Calling this will change how shorthand codes like "b" or "g" are interpreted by matplotlib in subsequent plots.

palette{deep, muted, pastel, dark, bright, colorblind}

Named seaborn palette to use as the source of colors.

setColor codes can be set through the high-level seaborn style

manager.

set_paletteColor codes can also be set through the function that

sets the matplotlib color cycle.
