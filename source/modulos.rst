modulos
=======

Para importar módulos en Python, utiliza la instrucción ``import`` seguida del nombre del archivo o librería. 
 

**Formas principales de importar**

* **Importar un módulo completo:** Usa ``import nombre_modulo``. Accedes a sus funciones con la 
notación de punto (``nombre_modulo.funcion()``).

* **Importar con un alias:** Usa ``import nombre_modulo as alias`` para acortar 
nombres largos o evitar confusiones.

* **Importar elementos específicos:** Usa ``from nombre_modulo import elemento`` para traer funciones o clases 
concretas sin usar el prefijo del módulo.

* **Importar todo el contenido:** Usa ``from nombre_modulo import *``, aunque puede 
sobreescribir nombres y no se recomienda en proyectos grandes.
